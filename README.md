**2TI LMailer** is a native Rust + Tauri v2 (~28 MB RAM) desktop Email, CalDAV Calendar, CardDAV Contacts, and Zero-Cloud Local Ollama AI Agent suite for **Zorin OS, Debian, Ubuntu, and macOS**.

> **Includes 30 Days Free Usage:** Claim your instant self-service Ed25519 evaluation key at [https://2tinteractive.com/apps/portal](https://2tinteractive.com/apps/portal).

## 1. Install via Official APT Repository (Zorin OS / Debian / Ubuntu)
```bash
curl -fsSL https://2tinteractive.com/apps/apt/install.sh | sudo bash
```

## 2. Install via Direct `.deb` Package
```bash
curl -LO https://2tinteractive.com/apps/releases/2ti-lmailer-latest-amd64.deb
sudo dpkg -i 2ti-lmailer-latest-amd64.deb
```

## 3. Install via Homebrew Tap (macOS & Linuxbrew)
```bash
brew tap LebToki/tap
brew install --cask 2ti-lmailer
```
